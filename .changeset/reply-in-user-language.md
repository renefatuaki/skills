An `/engineering` session now replies and asks in the user's language. In about 16 sessions it answered and asked its questions in English, though the user writes German and their CLAUDE.md names German for the chat, because the playbooks write commits, issues and pull requests in English. Writing the reply in the core of the engineering skill gains a bullet that puts every chat reply, every status line and every `AskUserQuestion` question, header and option in the language the user writes in, or the one their CLAUDE.md names, while commits, issues, pull requests, reviews, code and comments stay English. The teach skill explains in plain spoken words in the user's language instead of in plain spoken English.
