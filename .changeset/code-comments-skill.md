Add the code-comments skill with a guide per language and a PostToolUse hook that checks every written comment for long dashes, semicolons, length and unlinked TODOs. A comment links the plain-text form of a documentation page, `.md` on docs.github.com and code.claude.com, `.patch` on a commit URL and raw.githubusercontent.com for a file, so an agent that follows the link reads Markdown instead of HTML.
