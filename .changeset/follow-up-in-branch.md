Small follow-up work now lands in the ticket's pull request instead of a new ticket. In about twelve sessions an interactive ticket run filed new issues for drift and small fixes the user wanted in the same pull request. The follow-up judge of the Ticket playbook now runs in every run, not only in an auto run. Small work in code the ticket's diff already changes lands in the branch as its own commit with `Refs`. A new ticket is created only for work the ticket lists under Out of scope or work in another repository. Other work the judge keeps out goes to the Notes for the reviewer as "needs your call". Step 6 of the Feature playbook says the same.
