Add the issue skill. It installs issue forms for bug, feature, chore and epic plus config.yml when a repository has none, creates the labels they set, interviews the user with grilling when the request leaves a field open, prefills GitHub's form through a URL that a bundled script builds and checks against GitHub's length limit, opens it in the browser for review, decides the project fields such as priority and size, splits an epic into a parent and sub-issues, and attaches the interview as the first comment. When another skill asks for the issue, it creates it with gh instead.
