The `next-steps` skill now triggers on the end-of-session questions, such as whether anything is still open or ticked off and whether the session can be closed. In a directory that is no git repository, its script reads every git repository one level below it, folds ticket worktrees into their repository and names the repository in each line. Each point is marked as one the agent does or one only the user does, and one question after the list offers to do the agent's points now.
