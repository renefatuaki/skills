Add the engineering skill and the engineer agent. `/engineering` works every task through the playbook that matches it, Feature, Bug fix, Refactoring, Investigation, Perf issue, Hillclimb, Runtime forensics, Trace forensics, Prototype, Visual parity, Authoring a skill, Eval, Autonomous run, Session pickup, Worktree cleanup and Opening a PR, with the non-negotiables, the principles index and the autonomy, subagent and reply rules of pstack. `/engineering #<issue>` routes to the Ticket playbook, which works a GitHub issue to a pull request in its own worktree `../<repo>-<number>`. It grills only a criterion that reads two ways, a contradiction or a choice the user would see, settles a technical fork through the Prototype playbook, opens the playbook the label names, implements independent criteria in parallel through the engineer agent and commits criterion by criterion. interrogate reviews the diff with a second model family, blast-radius runs when the diff changes a schema, a public API, the dependencies or a flag, and a stuck test goes to attack-the-premise and then to the user. The skill is hidden from the model and bundles the script that sets the Status of a ticket.
