Add the project skill. It gives an owner a GitHub Project with the Status, Priority and Size fields the issue skill sets, by creating one or extending a chosen project. A bundled script applies the field set, keeps the values of the items and drops an option beyond the set only when told. Size XL is a full day of work. The skill links the project to the repository and lists the workflows and views that stay manual. It is hidden from the model, and the issue skill reads it by path when the owner has no project or the chosen one lacks the fields.
