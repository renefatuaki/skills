Add the project skill. It gives an owner a GitHub Project with the Status, Priority and Size fields the issue skill sets, by creating one or extending a chosen project and applying the field set from a bundled JSON through a script that keeps item values and refuses to drop options beyond the set unless told, then links it to the repository and lists the workflows and views that stay manual. The issue skill calls it when the owner has no project or the chosen one lacks the fields.
