The new `next-steps` skill lists what is still open in the order to do it, one short line per point. Every open pull request of the repository comes with its next action from GitHub as it is now, such as resolving conflicts, fixing checks, reviewing with the open test steps or merging, in the order of the `review-queue` skill. The open points of the session that GitHub does not show join the list.
