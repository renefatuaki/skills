The `today-issues` skill now starts without its slash command. Questions about which ticket comes next went to `next-steps` or to an improvised board scan that recommended blocked tickets, and every question about what could run overnight was answered by hand. The skill now triggers on which ticket comes next, what to work on today or in parallel, and what can run overnight or unattended, in any language. Started that way, it asks before it starts a ticket's session, changes the board or closes an issue. An overnight request plans an auto run of XS and S tickets whose criteria are complete and that have no open blocker.
