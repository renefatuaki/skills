Google Antigravity is a third model family next to Claude and Codex, for read-only work. A role in `~/.claude/rules/models.md` takes `antigravity:<model>/<effort>`, such as `antigravity:pro/high`. The models are `flash`, `pro`, `argon`, and `carbon`, ascending by strength, and the efforts are the ladder `low`, `medium`, `high`, `xhigh`, and `max`. A Gemini model lists only some efforts, so a slot runs the newest version of the model at the exact effort or the nearest effort it lists, and prints a note when they differ. Antigravity never writes code, so an entry is allowed only in `interrogate reviewers`, `arena cross-judge pool`, and `swarm workers`, never in `arena runners` or `architect runners`. The skill defaults stay unchanged. A slot runs through the new `forge:antigravity` agent and the `antigravity.mts` script of the engineering skill. Before a run the script reads the Gemini usage with `/usage` of `agy`, and the slot falls back when less than the `antigravity minimum` line is left, 20% without the line. `/setup-models` offers the entries, asks for that minimum, and shows the slug each model runs today and the usage left per Gemini group. The band above the prompt shows the Antigravity usage next to the Codex usage, such as `Antigravity week 91%`. Your settings decide whether `agy` denies a write, so inside a git work tree the script also fails a run that changed a file. When Antigravity fails, the slot runs on the Claude model of the same rank, `sonnet` for `flash` and `opus` for the others. A task you hand to Antigravity in your prompt runs as a read-only slot too.
